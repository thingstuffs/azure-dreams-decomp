# Naming and module evidence

A useful name states what the evidence supports. Byte equality establishes
the generated bytes; it does not establish a function's meaning or recover a
source filename by itself. Use this index to find the relevant evidence before
changing a name, type or compilation boundary.

## Where to look

| Evidence | Location | What it supports |
|---|---|---|
| Assertions with source filenames and line numbers | [Assertion sites](evidence/konami_assertion_sites.md), `ledger/evidence/assertions.jsonl` | Original filename text and ordered sites. A full TU boundary still needs surrounding evidence. |
| Debug expression strings | `ledger/evidence/dev_identifiers.json` | Original variable/member/type spelling where the printed expression identifies it. An expression alone may not identify its owning file. |
| Script symbol dump and call-table mapping | [Script call-table investigation](evidence/script_call_table_20260908.md), `ledger/evidence/script_symbols.json`, `include/script_symbols.h` | Developer identifiers and numbers. The corrected record layout is `name[32]` followed by a 32-bit value; call number n selects entry n. |
| Verified randomizer address facts | [Address-map evidence](evidence/adrando-findings.md), `ledger/evidence/adrando_map.json` | Table locations, layouts and code-site roles. A patch-site label need not describe an entire function. |
| Resident dispatch tables | `ledger/evidence/vm_tables.json` | Which function handles a numbered slot; the handler's meaning needs further analysis. |
| Prior function notes | `ledger/evidence/knowledge/` | Candidate explanations to check against the current code. |
| Applied function/global names | `config/names.tsv`, `ledger/names.jsonl` | Current alias spellings and their stated evidence. |
| Shared layouts | `include/shared/`, `include/records/`, [type consolidation](TYPE_CONSOLIDATION.md) | Field offsets and accesses; unknown field names remain honest limits. |

The script-table investigation retains its original chronology and corrections.
Do not copy the superseded entry-number offset from an early paragraph or an old
name receipt. Use the current symbol header and corrected parser results.

Inspect an example row from the repository root, without a disc:

```sh
python3 tools/evidence.py show town/func_8032F844
```

`tools/evidence.py` joins the committed facts into per-row evidence. Resolve the
row's source with [SOURCE_LAYOUT.md](SOURCE_LAYOUT.md). Generated status reports
coverage; old research-note counts are measurements of their stated snapshots.

## Applying evidence

Keep proven original developer names. New function and global names use
snake_case, types use PascalCase, and macros use UPPER_SNAKE_CASE. Keep names
unique within a link (resident executable plus the selected overlay). Do not
infer a semantic name from an address alone. See [SYMBOLS.md](SYMBOLS.md) and
[decisions 61 and 63](evidence/r97_decisions.md).

Function/global aliases are recorded in `config/names.tsv`; the build's alias
lowering retains canonical address symbols. Member names belong in the shared
type declaration. A shared-header edit needs verification of every dependent
row, including users whose source text did not change.

Assertions can anchor membership in original objects such as `lshop.c`,
`main.c`, `player.c` or `c_server.c`. Keep the text and line constants that
affect retail bytes. Use adjacency, section order, private storage and load
evidence to establish the rest of a TU. Label inferred groupings as inferred.
An asserted filename on one function does not authorize renaming a mixed
collector after that file.

Debug/development copies remain subject to the same evidence rules. A copy or
an apparent debug purpose does not prove runtime unreachability; moving code
to leftovers requires the separate reachability evidence in decision 68.

## Reproduction and limits

Committed evidence is usable without the disc. Re-extracting script symbols
requires a user-owned disc already extracted by setup:

```sh
python3 tools/evidence.py import --town-bin work/disc/containers/TOWN_TOWN.BIN
python3 tools/evidence.py build
```

These commands regenerate evidence, so review their output as a change. Keep
research receipts compact and retain hashes for archived detail; do not add
retail binary payloads to evidence. The [decision record](evidence/r97_decisions.md)
preserves earlier rulings and their later amendments.
