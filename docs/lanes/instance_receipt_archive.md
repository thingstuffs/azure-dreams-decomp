# Archived instance attestations and ledger-only coverage

The event ledgers preserve the original proof epochs. Instances whose current
source bytes or registered recipes changed receive append-only partial events
and do not count as current proven coverage. Refresh their links before credit.
No source or rowbase guard was rebound. New canonical module certificates remain
the ordinary lander's responsibility.

The 84,216 receipt files and 59,763 compiled-artifact files are archived outside Git in
`delivery/groups/09_instances/receipts.tar.zst`; use the unchanged receipt paths
as archive member names and validate the sibling SHA-256/roundtrip receipt.
`tools/coverage.py` reads only ledger attestations, not receipts or binaries.
Unknown bytes and estimated code remain separate from proved C coverage.
