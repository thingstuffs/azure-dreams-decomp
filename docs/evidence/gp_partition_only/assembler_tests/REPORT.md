# Generic assembler test migration, private review

The production assembler package ran 417 tests with three existing `casesi` failures. Both the guarded candidate and its generic-before package produced the same 13 failing test names in the overlay agent's baseline: those three, nine assertions that still expected `.extern` metadata in output, and one test that expected a load-delay nop for a true small external. `production_unit.log` is the isolated 417-test production run with the package path set explicitly.

I copied the suite into this private directory and changed seven test files; `test_updates.patch` contains the exact diff against production. The nine metadata assertions still compare entire instruction lists, now without the consumed `.extern` lines. The three local-table `casesi` assertions compare exact `$at` macro sequences; [fidelity_step1_aspsx_diff.md](../../../../docs/evidence/fidelity_step1_aspsx_diff.md) records that the historical local-table rewrite had already been removed. The GP test now checks both sides: a true `.extern` has no artificial nop, while a locally owned `.comm` emits the GP-relative store with its required nop. This follows the same evidence document's measured genuine-ASPSX external-address model. No assembler behavior was changed or pass disabled.

The copied full suite binds the CLI and package to `work/native_lane/selfinc_local_guard/candidate`, and all 418 tests pass. The extra test is the explicit locally owned GP hazard. This stronger binding exposed one fixture difference hidden by the original main-golden test's production `toolchain/maspsx` CLI path: direct candidate CLI+package output removes six `.extern` metadata lines, with every other line identical. `golden_delta.patch` records the exact six-line deletion. The private main-golden test pins the full candidate output SHA-256 and asserts no emitted `.extern` directive, preserving a full-stream regression check.

The private suite is a test migration for the generic transition. It does not itself certify a new assembler or production change. The small-extern delay-slot store macro remains covered as an unchanged pass-through case, without claiming that genuine ASPSX makes it GP-relative. Exact commands, hashes, failure sets, and file bindings are in `receipt.json`.
