# CD cohort source review

Scope: seven private trial sources and `include/slus/cd_cohort_types.h`, compared with their exact current `src/slus` counterparts. This is a source review; I made no source changes or new builds. File hashes and machine-readable findings are in `source_review.json`.

The shared driver declaration is an observed 12-byte prefix: fields are at offsets 0, 4, 5, 6, 8, and 10, and all three trial users select `D_80083958[0]` only. It avoids the old E758 40-byte padded view, which would extend across the separately addressed queue beginning at `0x80083968`. The incomplete array declares no historical allocation bound or ownership. E34C writes zero to the changed signed/unsigned fields, E758 already used unsigned counters/flags, and F5AC reads the same byte at `0x8008395c` as its old standalone alias. These source changes preserve the observed field operations, subject to the combined compiler proof for new address forms.

The queue view has a 24-byte stride, with byte 0, word 4, bytes 8–22, and byte 23 at the same offsets as E758's old view. Its 32 entries describe the observed ring access, not an ownership claim. F2A4's new `u32` word at offset 4 represents the pointer payload's 32-bit bits on the target; the two loads and store remain at offset 4. The retail function has `lw` at `0x8003f2e4` and `0x8003f2f8`, then `sw` at `0x8003f314`. The existing `raw_word_receipt.json` for this exact source hash reports 31/31 projected retail words, zero mismatches, in stock, generic, and genuine modes. Its raw relocatable comparisons mask three GP relocations, so the projected result is the relevant retail claim. The source queue is software data at `D_80083968`; no observed access establishes an MMIO contract. The old member was `S_8003F2A4_pair *volatile`, while the trial's cast `u32` lvalues are nonvolatile. This removes a C-level requirement for two separate reads and a store in other optimizer contexts, even though this compiler/recipe emitted precisely those accesses. It may have been a code-generation device; retail alone cannot settle original source intent. The integer/pointer conversion also assumes the target's 32-bit representation.

The seven files are independent trial units, not directly includable members of one owner TU: each defines the same 11 scalar/result globals. A combined owner must emit one definition set. The local `D_800814D3` base declarations also conflict across E758 `[2]`, F368 `[16]`, and F624 `[8]`; preserve each proven address-generation shape by a deliberate compatible combined-TU solution and verify codegen. E758's narrowed `D_800814D1[1]` still has a comment saying `size>8`, which is stale. The old F240 source additionally declares an incompatible byte-only `D_80083968` entry type; a combined F240 member must use the shared queue type (the root's current F240 candidate reportedly does).

F368, E4FC, and F624 trial bodies match their current production counterparts after the added definitions. The remaining cohort changes are the explicit driver/queue type substitutions, E758's local alias bounds, F5AC's base-plus-four field read, and F2A4's raw word access. No shared-header declaration here establishes storage ownership, a historical allocation extent, or combined-TU retail equivalence. A combined compile must check declaration compatibility and all affected complete function bodies.
