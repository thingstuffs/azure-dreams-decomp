# CD cohort private generated-link proof

The reviewed `cd_command_state` candidate passed a private generated-build
trial on the `89b14658` production baseline. The stage replaces seven whole
CD objects with one eight-function owner and partitions `func_8003F240` from
the existing code2 collector. Production files, active objects, and the
production SLUS image were unchanged before and after the trial.

The generated graph has 24 modules, 863 physical outputs, and the same 884
logical rows. Only the seven member recipes change in the private graph, to
CDK `-G32`. The F240 code2 partition renders byte-for-byte as the reviewed
part. The code2 remainder emits exactly its other 22 functions, whose 224
function words have the same normalized tokens as the current production
object. The connected code/code2 ownership closure has 195 functions; this
is a coverage claim, not a genuine-equality claim for either collector.

The new owner was compiled with the guarded generic assembler, then the
normal generated link ran without rebuilding it under the stock assembler.
The actual linked owner, a fresh generic compilation, and genuine ASPSX
2.79-q each emit exactly the declared eight functions and 1,041 words.
Their complete function streams compare exactly and each has zero retail
differences and zero masks. The generated full image is byte-identical to
retail (`ae19d8d4bdd2db9a933b1e44d70dd61be670781e441d7cb37da85250a7aed31f`),
and the generated SHA-1 gate passes. All eleven named data pieces have their
declared linked addresses, sections, and payloads. The source asset was
byte-identical to production, including gaps. All 861 active outputs outside
the seven removed members and changed code2 remainder were byte-identical to
their production counterparts.

The private [receipt](receipt.json) records those checks and matching
before/after snapshots of 27 pinned candidate, tool, and header inputs.
The stage, compiler/assembler outputs, and compile/link/gate logs are retained
in this directory. This is evidence for selective generic assembly of the
new owner in an isolated full link; it does not authorize production
activation or a global assembler transition.
