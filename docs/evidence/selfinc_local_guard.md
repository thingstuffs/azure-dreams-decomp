# Local small-data guard for `_fold_selfinc_la`

Measured 2026-09-24. This is evidence for a **private generic maspsx candidate**, with every pass enabled. The guard prevents `_fold_selfinc_la` from rewriting an `la` to a symbol defined in the translation unit's `.sdata` or `.sbss`; the later address expansion handles that symbol. The exact [guard diff](selfinc_local_guard/guard.diff) adds one membership check to the existing known-small-data guard. It does not disable or retire `_fold_selfinc_la`.
