// Every range below is PSY-Q library code, matched byte-for-byte against
// toolchain/psx_psyq_signatures/<ver>/*.json (port/tools/psyq_sigmatch.py); the
// yaml now carries it as `asm, psyq/<lib>/<obj>` segments. REAL names, never
// `func_` -- a func_ label would put library code into the decomp denominator
// (tools/gen_sizes.sh only keeps ` F ` symbols named func_[0-9A-Fa-f]+).
// Three static helpers appear once per object and cannot share one linker
// symbol, so the second/third copies are suffixed: memclr_vb / memclr_dma
// (LIBETC INTR_VB.OBJ / INTR_DMA.OBJ) and memset_gpu (LIBGPU SYS.OBJ, distinct
// from the libc `memset` at 0x80069ee8).
// `size:` is spelled out wherever a function has to swallow a trailing
// shared-epilogue fragment or an in-object data/padding tail, so spimdisasm
// cannot invent a `func_` row for it (same device as StCdInterrupt size:0x970).
// ---------------------------------------------------------------------------
